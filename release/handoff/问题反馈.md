# 问题反馈

[返回 README](README.md) · [验收指南](验收指南.md)

反馈时请提供 **出错步骤、截图和 Diagnostics ZIP**，并注明 Build：`0.1.0-rc.1-e6beb5af2de4`。

## 启动器可以打开

1. 点击启动器右上角的 **诊断**。
2. 选择 **导出诊断…**，保存到自己选择的位置。
3. 按下方模板记录操作步骤，并附上相关截图及诊断 ZIP。

默认诊断 ZIP 不包含聊天正文、凭证、图片或作品。

## 启动器无法打开

先提供安装包版本和 Windows 错误提示截图，并注明从哪里启动。无需导出当前无法取得的诊断。

遇到登录或联网异常时，记录具体提示；Clash 继续使用自己的有效配置，不要复制开发者配置或切换到固定端口。

## 保留现场

不要删除场景、对话历史或缓存来尝试修复；缓存可能包含未保存作品。不要发送认证文件、Clash 配置或整个用户目录。
